# FreshLoop — Smart Food Waste Reduction Assistant

**Use it before you lose it.**

FreshLoop is a lightweight web application that helps people keep track of food at home, identify items approaching their expiry dates, and find practical ways to use them before they are wasted.

## The problem

Food is often thrown away because people forget what they have or do not notice that an item is approaching its expiry date. FreshLoop makes that information easier to see and act on by organizing food according to expiry urgency.

## The solution

Users add their own food items to FreshLoop. The application calculates a **Smart Rescue Score**, sorts the inventory by urgency, and displays relevant food-use suggestions. Users can then mark an item as used or wasted and track the results.

FreshLoop starts with an empty inventory. It does not preload sample or demo food. The dashboard reflects the information entered by the user.

## Main features

### 1. Personal food inventory

- Add a food item by entering its name, category, and expiry date.
- Choose from categories: Fruit, Vegetables, Dairy & Eggs, Bread & Bakery, Meat & Fish, Leftovers, and Pantry & Other.
- FreshLoop can suggest a category when it recognizes a food name; the user can still choose a category manually.
- Use quick date shortcuts for Today, Tomorrow, +3 days, or +1 week.
- Search the inventory by food name.
- Filter items by All, Urgent, Soon, or Fresh.

### 2. Smart Rescue Score

Each item receives a score from 0 to 100 based on the number of days remaining until its entered expiry date. A higher score means the item needs attention sooner.

| Expiry timing | Score | Status |
|---|---:|---|
| Already expired | 100 | Use today* |
| Expires today | 90 | Use today |
| Expires within 1–2 days | 75 | Use very soon |
| Expires within 3–5 days | 50 | Plan it |
| More than 5 days remaining | 20 | Fresh |

Items are sorted from the highest score to the lowest, with expiry timing and food name used to order items when scores are equal.

*An expired item is shown with its expired date and a safety caution instead of a recipe suggestion. The score is a prioritization indicator, not a food-safety assessment.*

### 3. Food-use suggestions

FreshLoop provides suggestions using a simple, explainable rule-based system:

- It first checks the food name for known keywords and uses a matching suggestion when available.
- If no keyword-specific suggestion is found, it selects an idea from the item's category.
- Items with more than five days remaining are treated as not needing immediate action.
- Expired items receive a caution message rather than a suggestion to consume them.

The suggestions are built into the application. They are not generated by a trained AI model or an external AI service.

### 4. Rescue priorities and combination ideas

The **Use these first** section highlights up to three items with the highest urgency scores. When the inventory contains recognized combinations of ingredients, FreshLoop can also display a simple combination idea, such as banana smoothie, shakshuka, or French toast.

### 5. Track used and wasted food

For each inventory item, the user can select:

- **Used it** — removes the item from the active inventory and increases the rescued count.
- **Tossed** — removes the item from the active inventory and increases the wasted count.

The dashboard updates its statistics automatically:

- **Items tracked:** number of items currently in the inventory.
- **Need attention now:** number of items with a score of 75 or higher.
- **Rescued from the bin:** number of items marked as used.
- **Waste-free rate:** used items divided by all items marked used or wasted.

### 6. Copy rescue plan

The **Copy rescue plan** action creates a text summary of inventory items with a score of 50 or higher and copies it to the clipboard. The plan includes each item's name, expiry timing, and relevant suggestion or safety message.

### 7. Persistent browser storage

FreshLoop saves inventory items and tracking counters in the browser using `localStorage`. Data remains available after refreshing the page in the same browser and on the same device. The **Reset all** action clears the inventory and resets the counters after confirmation.

## Technology

- **HTML5** — application structure and forms.
- **CSS3** — visual styling, layout, animations, and responsive behavior.
- **Vanilla JavaScript** — scoring rules, recommendations, inventory interactions, filtering, statistics, and clipboard behavior.
- **Browser localStorage** — saves the user's inventory and counters locally.

The project does not require a backend, database, framework, API key, or external AI service. Google Fonts are requested for the typography; when they cannot be loaded, the browser uses fallback fonts.

## Project structure

Keep the three files together in the same folder:

```text
FreshLoop/
├── index.html
├── style.css
└── script.js
```

- `index.html` contains the page structure and links the stylesheet and JavaScript file.
- `style.css` contains the green visual theme, glass-style cards, layout, responsive rules, and component styling.
- `script.js` contains the food categories, suggestion rules, Smart Rescue Score, rendering, event handlers, statistics, clipboard action, and local storage logic.

## Run the application

FreshLoop is a static web application and does not need an installation or build step.

1. Download or clone the project folder.
2. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
3. Open `index.html` in a modern web browser.
4. Add food items using the form. The inventory starts empty; no sample data is inserted automatically.

An internet connection is only needed to load the optional Google Fonts. The main application logic runs in the browser.

## Suggested manual test

To verify the main features without adding demo data to the application:

1. Add one item with today's date, another with an expiry date two days from today, and a third with an expiry date one week from today.
2. Confirm that the scores and status labels differ and that the most urgent items appear first.
3. Search for an item by name and try the Urgent, Soon, and Fresh filters.
4. Check that the suggestion changes according to a recognized food name or its selected category.
5. Mark one item as Used and another as Tossed; confirm that the statistics update.
6. Use Copy rescue plan when at least one item has a score of 50 or higher.
7. Refresh the page and confirm that the remaining inventory and counters are still present.
8. Use Reset all to clear the test entries and restore the empty state.

These entries are added manually for testing; they are not built-in demo data.

## Important notes and current scope

- FreshLoop is a rule-based food organization assistant. It does not use machine learning, computer vision, barcode scanning, or an AI API.
- Recommendations are predefined suggestions based on food-name keywords and categories; they are not personalized recipes or food-safety advice.
- The current inventory form stores a food name, category, and expiry date. It does not currently track item weight, units, or portions.
- Expiry dates are entered by the user. FreshLoop cannot inspect food or determine whether it is safe to eat.
- Data is stored locally in the browser, not in an online account or cloud database. Clearing browser site data may remove the saved information.
- There is no login, multi-user synchronization, or server-side storage.

## Practical impact

FreshLoop aims to make household food management more visible and actionable. By highlighting items that need attention, suggesting simple ways to use them, and tracking items marked as used or wasted, it encourages users to make more informed decisions and reduce avoidable food waste.

## Future development

Possible extensions include quantity tracking, optional expiry reminders, barcode-assisted item entry, richer recipe matching, and cloud synchronization. These are future possibilities and are **not** part of the current implementation.
